# WBS WEBSITE MASTER KONZEPT V3.0

# Projektziel

Die WBS-Website ist das wichtigste Referenzprojekt des Unternehmens.

Sie verkauft keine Websites.

Sie verkauft Vertrauen, Qualität, Professionalität und langfristige
Zusammenarbeit.

Der Besucher soll innerhalb von 3--5 Sekunden denken:

> "Genau so soll meine zukünftige Unternehmenswebsite aussehen."

# Hero

## Grundidee

Der Hero zeigt **keinen Monitor, kein Smartphone und keinen Arbeitsplatz
mehr**.

WBS verkauft Websites.

Deshalb steht die Website selbst im Mittelpunkt.

Die rechte Seite zeigt eine große Browser-Vorschau einer
Premium-Unternehmenswebsite.

Sie wirkt wie eine hochwertige Live-Präsentation.

Keine Geräte.

Keine Mockups.

Keine Render.

Nur die Website.

------------------------------------------------------------------------

## Linke Seite

-   Eyebrow
-   Rotierende Headline
-   Beschreibung
-   Zwei CTA Buttons
-   Trust Elemente

Headline:

-   Vertrauen schaffen.
-   Wirkung zeigen.
-   Wachstum begleiten.

Sanfte Crossfade-Animation.

------------------------------------------------------------------------

## Rechte Seite

Eine große Browser-Vorschau.

Sie nimmt ungefähr 50 % der Hero-Breite ein.

Sie besitzt:

-   Browser-Leiste
-   Tabs
-   Adresszeile
-   komplette Landingpage
-   hochwertige Bilder
-   Premium Typografie

Der Browser wirkt modern und minimalistisch.

Keine übertriebenen Schatten.

Keine Spielereien.

------------------------------------------------------------------------

## Dynamische Demo-Websites

Die Browser-Vorschau wechselt automatisch zwischen:

-   Bauunternehmen
-   Immobilien
-   Restaurant
-   Rechtsanwalt
-   Arztpraxis

Jede Demo besitzt:

-   eigenes Logo
-   eigene Navigation
-   eigene Headline
-   eigenen Hero
-   eigene CTA
-   eigene Farben
-   vollständige Landingpage

Die Übergänge erfolgen ausschließlich über ruhige Crossfades.

# Bestehende Website

Die bestehende Website bildet die Grundlage.

# Wichtigste Designentscheidung

Die bisherige Hero-Idee mit Monitor und Smartphone wird bewusst
verworfen.

Grund:

Sie erzeugt unnötige Komplexität und lenkt vom eigentlichen Produkt ab.

Der neue Hero stellt die eigentliche Leistung in den Mittelpunkt:

**Hochwertige Websites.**

Der Besucher soll sofort sehen, welche Qualität WBS entwickelt.

**Show, don't tell.**
